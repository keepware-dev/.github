### For Claude Code and other agents

| | |
|---|---|
| [**Tillerman**](https://www.keepware.dev/tillerman) | A desktop workbench for Claude Code: sessions on every computer you use in one list, watched and steered from any screen. Work for several teams on one computer — switch the team and the Claude account, connections and secrets your agents use switch with it. macOS, Windows, Linux. Free for personal use. |
| [**WakeAgent**](https://www.keepware.dev/wakeagent) | Your AI agent stops waiting. When CI fails, a PR gets a review or a Jira issue moves, WakeAgent wakes the session that was waiting — busy, idle or closed — instead of letting it poll. Free. `npx -y @keepware/wakeagent login` |
| [**CC Cadence**](https://www.keepware.dev/cc-cadence) | Chat with Claude and any Anthropic-compatible model right inside VS Code, on your Max subscription — or several Claude accounts, one per tab. Free. ([repo](https://github.com/keepware-dev/cc-cadence)) |
| [**QuerentDB**](https://www.keepware.dev/querentdb) | MySQL, PostgreSQL, MongoDB, Redis and Elasticsearch in one window, with an AI agent beside every query that only proposes writes. A local MCP server lets Claude Code and Cursor query your databases with your permissions. Free for personal use. |
| [**Pentimento**](https://www.keepware.dev/pentimento) | Design systems, designs and sites with comments, versions and an AI agent that edits beside you; Claude Code reads and edits designs through MCP. Free for personal use. |

### Everyday tools

| | |
|---|---|
| [**ClipBridge**](https://www.keepware.dev/clipbridge) | Copy on your Mac or PC, paste on your Android phone or tablet. End-to-end encrypted, with no history. Free. ([repo](https://github.com/keepware-dev/clipbridge)) |
| [**StampLens**](https://www.keepware.dev/stamplens) | Select any timestamp or date — Unix seconds to nanoseconds, ISO 8601, log formats, ObjectId, UUID v7, ULID — and read it in your time zone. In the browser and any app. Free. |
